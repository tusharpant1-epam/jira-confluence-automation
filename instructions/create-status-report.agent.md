description: Create a concise weekly status report in Markdown.
---

Generate a weekly status report in Markdown format.

- Use exactly these sections in order: `## Accomplishments`, `## Blockers`, and `## Next Week`.
- Use bullet points only under each section.
- Keep the total output to 20 lines or fewer.
- Use a professional tone with direct, factual language.
- Remove fluff, filler phrases, and generic statements.
- Include specific outcomes, current issues, and near-term priorities.
- Do not include tables, paragraphs, or extra commentary outside the sections.
